# EduAssist Suite & Open Web Tools

A lightweight, open-source collection of interactive web utilities, educational modules, and developer scripts designed to run directly in modern browsers without bloated dependencies.

## 🚀 Overview

This repository provides zero-dependency educational workflows, utility algorithms, and client-side interfaces. The objective is to keep tools fast, responsive, and easily accessible on low-bandwidth networks and mobile environments.

## ✨ Features

- **Zero Runtime Bloat:** Clean, dependency-free HTML5, modern CSS, and modular Vanilla JavaScript.
- **Mobile-First Accessibility:** Optimized UI designed specifically for handheld browsers and low-spec hardware.
- **CI/CD Ready:** Automated linting, code validation, and continuous deployment workflows configured with GitHub Actions.
- **Modular Utilities:** Reusable helper scripts for logic building, practice datasets, and web workflows.

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern CSS3, Vanilla ES6+ JavaScript
- **Automation & CI/CD:** GitHub Actions
- **Hosting/Deployment:** GitHub Pages / Static Cloud CDN
